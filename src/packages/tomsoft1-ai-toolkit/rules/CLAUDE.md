# Wspólne reguły zespołu AI

- Zanim edytujesz kod, przeczytaj aktualne konwencje repozytorium.
- Nie dodawaj sekretów do kodu, promptów, logów ani plików konfiguracyjnych.
- Preferuj małe, testowalne zmiany i nie zmieniaj plików poza zakresem zadania.
- Po zmianach przedstaw wynik testów oraz ograniczenia weryfikacji.
