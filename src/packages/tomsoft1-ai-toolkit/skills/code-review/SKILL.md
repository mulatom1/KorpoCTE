# Code Review — wewnętrzny skill zespołu

Przeczytaj opis zadania, diff i konwencje repozytorium. Oceń:
1. Poprawność i przypadki brzegowe.
2. Bezpieczeństwo wejść i sekretów.
3. Testy dla zmienianych ścieżek.
4. Prostotę i spójność ze stackiem.

Podaj wyłącznie problemy, które można uzasadnić fragmentem diffa.
Na końcu oddziel blokery od sugestii i dopisz listę testów do wykonania.
Nie wprowadzaj samodzielnie zmian do kodu.
